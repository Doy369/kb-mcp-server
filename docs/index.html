接口配置（两步搞定）

只需做两件事：① 让助手能查你公司的订单 / 库存（没有也可先用演示数据）；② 让回答更自然（可选）。全部保存即生效，不用改任何代码。

① 连接公司系统（查订单 / 库存）

把公司系统地址填下面，然后点【测试连接】，系统会自动认出「订单状态 / 承运商 / 到达时间」对应哪个字段——你不用懂代码。

登录验证（大多数系统需要，点开填）
点上面按钮，系统会连一次你的系统并显示结果。

② AI 智能回答（可选，更自然）

不填也能用：助手会自动从知识库里摘取原文回答。想让回答更通顺自然，接一个大模型即可。

③ 答案护栏（防止答非所问）

置信度低于阈值的答复会自动标记「需人工复核」，不会静默放行。留空用默认（bge 嵌入 0.5 / 离线嵌入 0.2），填 0 关闭护栏。

怎么用（三步）

第一步：在①里选「先用演示数据」，直接点【保存并应用】，助手就能答通用问题。
第二步：有真实系统时，选「连接真实系统」，填地址 →【测试连接并自动识别字段】→ 在下拉里选好字段 →【采用所选字段并保存】。
第三步：想更自然，在②点【一键用 DeepSeek】，粘贴 key，保存。保存后到右侧对话窗发一句「你好」即可验证是否接通。
